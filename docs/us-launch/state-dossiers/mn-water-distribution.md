## Credential and examination boundary

Minnesota’s current official program is the **Minnesota Department of Health Water Supply System Operator certification** program. The operative certification is for a person to operate a community or nontransient noncommunity **water system**, not for a separately titled water-distribution credential. [1] The Department of Health describes five water-operator certificate classes, A through E, whose levels are based on education, experience, and system requirements. [2] The official application identifies Water Supply System Operator Class A, B, C, and D examinations; it does not offer a distribution-only examination. [6]

Minnesota Rule 9400.1000 requires separate examinations for each designated system and facility **class**. It says that the examinations must account for, among other things, water distribution systems, but it does not establish a distribution-specific certificate, examination class, content allocation, or standalone examination. It permits testing across broad areas including basic science, mathematics, operating procedures, treatment processes, equipment, equipment maintenance, management, and state law and rules. [4]

Accordingly, the requested `mn-water-distribution` route has no current official, discrete credential/exam boundary. “Water distribution systems” is an element within Minnesota’s broader water-supply-system class examinations, not an identified Minnesota distribution-operator examination family. The exact class boundary cannot be inferred for this stream: system classes A–E are assigned from aggregate system rating values that include source, treatment, distribution storage capacity, number of wells, and affected population. [5]

The active official program materials do establish that applicants must meet class qualifications and pass an examination; for example, the Class D qualification requires a high-school diploma or equivalent plus either one year of qualifying experience or an approved postsecondary water/wastewater-technology program. [3] That eligibility information does not turn Class D, or another class, into a distribution-only examination.

## Source freshness and conflicts

The Minnesota Department of Health’s program, FAQ, exam-information, and study-material pages are current agency pages marked January 11, 2026. They confirm an active, class-based water-supply-system operator examination program. The Minnesota Office of the Revisor pages are the current official rule text retrieved from the state’s official rules publisher. The version pages for Rules 9400.0700 and 9400.1000 identify October 2, 2007 as the electronically published version, so the operative rule language is older but remains the current official text presented by the Revisor. [3] [4]

There is a material document-age discrepancy in public class labels. The current MDH FAQ and study-material page describe Classes A–E, and Rule 9400.0700 contains a Class E qualification. [2] [3] The application form linked from the current MDH exam-information page is dated February 1, 2018 and lists only Class A–D. [6] This discrepancy is not used to claim that a particular class is unavailable. It reinforces that the form cannot serve as a current content blueprint or as evidence for a separate distribution examination.

There is no conflict about the central route boundary. The current agency pages, application, and rules consistently use Water Supply System Operator class labels rather than a water-distribution credential or examination. The rule’s mention of water distribution systems establishes only that distribution can be considered within class examinations; it does not identify a distinct distribution test. [4]

No current official Minnesota candidate handbook, public distribution examination outline, public class-specific content outline, job-analysis domain list, or official distribution exam reference list was located in the reviewed program materials. MDH says subject lists are available by classification on request, but no current content was publicly available for verification during this dossier work. [7]

## Decision and bank recommendation

**Decision: Hold.** Minnesota has an active, official water-supply-system operator certification program, but the requested **Minnesota water-distribution** route is not a current official credential or examination boundary. The only official reference to distribution in the exam rule is as one factor in class-based examination design. [4] System classification is itself whole-system and includes multiple non-distribution factors. [5] Current official sources also do not supply a public, class-specific or distribution-specific examination outline adequate to trace a limited technical candidate dossier. [7]

This is a route-compatibility and evidence-boundary hold, not a finding that Minnesota’s operator-certification program is inactive. It should be reconsidered only if MDH provides a current official distribution-specific examination designation or releases an official, current class-specific content outline that explicitly supports a narrowed exam target. A future separate research route could examine a named Minnesota Water Supply System Operator class only after confirming its current public blueprint and resolving the current application/class-label discrepancy; that would not validate this `mn-water-distribution` route by inference.

**Bank recommendation:** **Do not propose, create, name, or reserve a unique bank.** No unique Minnesota water-distribution bank is evidence-supported. Do not map the route to an existing generic water-distribution bank or infer equivalence from the rule’s general mention of distribution systems. If a later official source establishes a valid candidate boundary, perform the required read-only recovery and overlap check against any pre-existing U.S. Class I water-distribution packages before considering any new bank identity.
