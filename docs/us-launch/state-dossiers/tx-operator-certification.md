## 3. Topic lists, need-to-know criteria, no weights

All lists below are need-to-know criteria. They are **not** weighted, and no question counts are published. Do not turn them into a blueprint.

### 3.1 Wastewater treatment plant, Class D (source 1)

Twenty categories, as named on the TCEQ page:

1. Statutes and Rules
2. Permits
3. Design Criteria (30 TAC Chapter 217)
4. Safety
5. Laboratory
6. Management
7. General Knowledge
8. Collection
9. Pumping
10. Preliminary Treatment
11. Primary Treatment
12. Ponds
13. Trickling Filters
14. Activated Sludge
15. Process Control
16. Disinfection
17. Sludge Digestion
18. Biosolids Disposal
19. Effluent Disposal
20. Math Problems

### 3.2 Wastewater treatment plant, Class C (source 1)

The same twenty category names as Class D. The page states that the Class C operator should have "thorough knowledge of all need-to-know criteria for lower levels", plus the Class C scope text for each category. The category names were compared against Class D and are identical. The Class C scope sentences were not compared line by line with Class D, so the difference in depth is not verified here.

### 3.3 Public water system, Class D (source 2)

Nine groups, as named on the TCEQ page. Individual criteria are in the source.

1. Rules/Regulations: 30 TAC Chapter 30 Subchapters A and K; 30 TAC Chapter 290 Subchapters D and F (drinking water standards)
2. Safety
3. General (public health, waterborne disease, bacteriological sampling, customer relations, water characteristics, hydrologic cycle, sources, recordkeeping, contaminant types, customer service inspections)
4. Groundwater (well contamination and protection, well components, well pumps and motors, groundwater treatment purposes)
5. Surface Water (source characteristics, surface water plant components and treatment)
6. Storage/Distribution (reservoirs, distribution components, meters, pumps, valves and pipe, cross-connections and backflow assemblies)
7. Disinfection (chlorinator start-up, shutdown and safety; chlorine reactions; chlorine gas first aid; chlorine residual testing)
8. Math (conversion units; water utility math using area, volume and dosage formulas)

## 4. Verdict per stream

Rule applied: Suitable only if the topics are verified and complete. Otherwise Narrow, with the reason.

| Stream | Verdict | Reason |
| --- | --- | --- |
| Wastewater treatment plant, Class D | **Narrow** | The 20 need-to-know categories and their scope text were read from the official page. The page is criteria for study, not an exam outline. No weights or question counts are published, so a bank cannot be balanced to the exam. The TCEQ exam is not described as matching these categories one to one. |
| Wastewater treatment plant, Class C | **Narrow** | Same reasons as Class D. The category names match Class D, but the Class C scope depth is stated only as "in addition to" Class D and was not compared sentence by sentence. | Public water system, Class D | **Narrow** | The nine need-to-know groups were read in full. The page is criteria for study, not an outline. No weights or counts are published. Several criteria are stated as "be familiar with" or "general knowledge" with no depth limit. |

TCEQ publishes need-to-know categories, not an exam outline. Narrow is therefore the correct result for all three streams. Suitable would require an official blueprint with weights or counts, which was not found. Source 5 (licensing homepage) was not read, so it cannot be ruled out as a source of a blueprint. That check is still open (section 6).
