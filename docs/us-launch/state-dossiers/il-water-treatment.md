# Illinois water treatment — state-specific readiness dossier

**Route ID:** `il-water-treatment`
**Exact state and stream:** Illinois (IL) — water treatment
**Existing matrix label:** state-specific
**Research retrieval date:** 2026-10-29
**Decision:** **Narrow**

## Credential and examination boundary

The relevant Illinois credential is the Illinois Environmental Protection Agency (Illinois EPA) **Certificate of Competency as a community water supply operator**. Illinois has four certification classes—A, B, C, and D—and the governing rule requires a separate examination for each class. [1]

For this water-treatment route, the defensible future review-only boundary is the **Illinois Water Supply Operator Class C examination**, limited to the **Class C treatment core: chemical feeding and calculation of dosage**. A Class C community water supply uses chemical feeding and is not a Class A or Class B supply. The full Class C certification and examination scope also includes pumpage, storage, and distribution; those are outside the treatment-core subset proposed here. [1]

This is not a general U.S. water-treatment credential, a distribution certification, a Class A or Class B treatment route, or a program for non-community water supplies. Illinois identifies non-community supplies separately through the Illinois Department of Public Health. [2]

Passing an Illinois examination results in Operator in Training status rather than full certification by itself. Full Class C certification also requires the applicable education and experience conditions; the rule specifies at least 1,780 hours of study, training, and hands-on experience, including at least 890 hands-on hours in chemical feeding and dosage calculation. [1] [3]

## Why the decision is Narrow

A current, state-specific credential and examination boundary exists. The Illinois Administrative Code defines the Class C facility category, sets the Class C competency scope, and requires a separate Class C examination. The current Illinois EPA examination request still asks candidates to select one examination level—A, B, C, or D—and the agency currently publishes 2026 and 2027 examination schedules. [1] [4] [5]

The public official materials are not sufficiently granular to support the entire Class C examination as a current question-bank package. Illinois EPA does not publish, in the current program materials retrieved, a Class C candidate handbook, detailed examination outline, content-domain weighting, or a public item specification. This limitation is material because the agency's 2025 program report states that developing a revised Class C examination was the focus of its 2026 annual examination-committee meeting. [2] [6]

Accordingly, the bounded treatment-core subset is suitable for future **review-only** candidate work only after each proposed candidate is traceable to the current rule and independently reviewed. It must not be represented as covering the full Illinois Class C examination, predicting item mix, or reflecting an unreleased 2026 revision.

## Learner-level scope and exclusions

**Intended learner:** An Illinois candidate seeking to take the Class C water supply operator examination, or a newly certified/Operator-in-Training Class C operator needing foundational, rule-aligned treatment knowledge. The learner is not presumed to be fully certified or authorized to serve as a Responsible Operator in Charge.

**Included boundary:**

- Class C facility classification as a chemical-feed community water supply that is not Class A or Class B.
- The high-level Class C treatment competencies expressly named in the rule: chemical feeding and calculation of dosage.
- Recognition that the state uses separate Class A, B, C, and D examinations and that higher treatment classes encompass additional processes.

**Excluded boundary:**

- Class A processes: coagulation, lime softening, ultraviolet disinfection, membrane filtration, sedimentation, and the full Class A scope.
- Class B processes: filtration other than membrane filtration, aeration and filtration, and ion exchange systems.
- The non-treatment elements within the full Class C scope: pumpage, storage, and distribution.
- Any facility-specific procedures, chemical selection or handling instructions, monitoring protocols, emergency actions, dosage values, statutory reporting duties, plant design, or local operating directions.
- Experience verification, application processing, renewal administration, reciprocity, non-community-water-supply certification, and claims about actual examination item counts, weighting, or question formats beyond the official materials.

## High-level source-supported objectives

Because the decision is Narrow, future review-only work may use only the following high-level objectives within the stated boundary:

1. Distinguish an Illinois Class C community water supply from the Class A, Class B, and Class D facility categories using the treatment-process classifications in 35 Ill. Adm. Code 681.200. [1]
2. Identify chemical feeding and dosage calculation as the treatment-specific competency area named for Illinois Class C certification. [1]
3. Recognize that Illinois administers a separate Class C water supply operator examination and that the Class C treatment core is narrower than the full Class C certification scope. [1]

These objectives are not an examination blueprint, test plan, or authority to infer unlisted subject areas.

## Source freshness and conflicts

The legal classification and separate-examination structure are current official requirements. The Illinois Administrative Code page shows Part 681 content current through an amendment effective December 4, 2025; the operative classification and examination provisions cite their November 13, 2017 amendment history, with no conflicting newer classification located in the current official part. [1]

The Illinois EPA's active examination request is revised December 2025 and still lists A, B, C, and D as the selectable examination levels. The agency's examination-schedule page lists 2026 dates and a 2027 schedule, which supports that the program remains active as retrieved. [4] [5]

The Illinois EPA FAQ aligns with the rule on the Class A–D facility classification and describes a passing score and experience thresholds. Where it summarizes classification, the binding rule controls. [1] [3]

No conflict was found between the rule, current program page, current form, schedule, FAQ, and program report about the existence of the Class C examination. The material readiness issue is not a contradiction: the agency's 2025 report says work on a revised Class C examination was a 2026 focus, but no corresponding current public Class C outline or replacement candidate handbook was located in the official program materials retrieved. Treat the public rule as the only authoritative content boundary until Illinois EPA publishes or directly confirms a current detailed examination outline. [2] [6]
