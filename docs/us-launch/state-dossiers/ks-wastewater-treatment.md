# Kansas wastewater-treatment operator certification — readiness dossier

**Route ID:** `ks-wastewater-treatment`
**State / stream:** Kansas (KS) / wastewater-treatment
**Existing matrix label:** state-specific
**Research retrieval date:** October 29, 2026
**Decision:** **Narrow**

## Credential and examination boundary

Kansas Department of Health and Environment (KDHE) administers a wastewater treatment operator certification program distinct from the water-supply program. Kansas law defines a wastewater treatment facility as the facility or group of units provided for wastewater treatment and defines an operator as the person directly responsible for supervising it. [5] KDHE's active certification page lists separate wastewater materials, including a current **Class II Wastewater Operator** examination-preparation document. [1] [2]

This dossier supports only the **Kansas KDHE Wastewater Treatment Operator — Class II written certification examination**. The scope is not the complete Kansas wastewater-treatment route, the Small System examination, or Classes I, III, or IV. The Class II document says explicitly that the examination evaluates introductory knowledge, including fundamental terms and definitions and principles of wastewater treatment processes. [2] The official application separately selects wastewater and Class II, and describes the required examination as written. [3]

KDHE's program structure has five wastewater certification classes: Small System, I, II, III, and IV. The 2025 Kansas Legislative Division of Post Audit report states that each class has its own certification examination. [8] That finding, together with KDHE's current Class II document, supports a separate Class II candidate boundary rather than a generic Kansas wastewater bank. The dossier does not assert an item count, score model, examination duration, or detailed weighting because the current Class II document supplies topic coverage but no official blueprint with those details.

## Readiness decision

**Narrow.** The current, official August 2026 Class II document is a specific examination-preparation scope and is adequate for a limited future candidate dossier. It does not establish a current common scope for all Kansas wastewater certification levels. The actively hosted all-level Class I–IV document is dated April 22, 2009, so it cannot expand this candidate boundary to Classes I, III, or IV. [9]

This decision authorizes no authoring, candidate package, review, database activity, release, or learner access. A future package may be considered only for the Class II boundary, must rely on source-traceable objectives, and must remain review-only until it completes the required structural and independent review controls.

## Learner-level scope and exclusions

The intended learner is a prospective Kansas **wastewater Class II** certification candidate. KDHE describes the examination level as introductory. [2] The eligibility context is separate from instructional scope: KDHE's current application requires the applicant's employment and experience to correspond to the wastewater examination type; KDHE's current guidance lists employment or ownership, a high-school diploma or GED, experience, and points as pre-examination requirements. [3] [4]

The future candidate boundary is limited to high-level recognition and foundational understanding of the current Class II topic list. It excludes:

- Small System, Class I, Class III, and Class IV examination coverage;
- water-supply, water-distribution, wastewater-collection, laboratory, and non-Kansas credentials;
- facility-specific operating directions, setpoints, chemical dosing, design calculations, equipment repair, emergency response procedures, and permit-compliance instructions;
- legal, reporting, notification, renewal, fee, and eligibility determinations beyond source-supported orientation to the credential; and
- any claim that a candidate package substitutes for KDHE-approved training, on-the-job experience, permit requirements, or examination materials.

## High-level, source-supported objectives for a future Class II candidate dossier

If a future review-only dossier is authorized, its objectives must stay at this level and be independently checked against the current KDHE Class II document:

1. Recognize foundational wastewater terminology and the purpose of principal treatment stages.
2. Describe, at a foundational level, activated-sludge components, biological roles, and related process terms identified by KDHE.
3. Recognize the purpose of preliminary treatment, primary clarification, final clarification, sludge processing, and waste-stabilization ponds.
4. Identify foundational chemistry, sampling, disinfection, solids, and wastewater-characterization concepts named in the KDHE Class II scope.
5. Apply only the high-level calculation domains named by KDHE: detention time, percent removal, concentration-to-load conversion, volume, surface area, and solids loading rate.
6. Recognize foundational collection-system, pump, maintenance, safety-awareness, recordkeeping, and emergency-response topics listed for the Class II examination without converting them into operational procedures or legal directives.

## Source freshness and conflicts

The freshest scope evidence is KDHE's August 2026 Class II examination-preparation document and the August 11, 2026 examination application. [2] [3] These documents are consistent with KDHE's live certification page. [1] The February 2025 legislative audit independently corroborates that wastewater is a distinct program with a separate examination for each level, but it is not a content outline and is used only for program-family confirmation. [8]

No direct conflict was found between the current Class II materials and the current 2026 statutes. The material limitation is coverage, not contradiction: KDHE still links a 2009 all-level wastewater document, while its current August 2026 document is expressly Class II only. [1] [2] [9] The older document cannot be used to infer that Class I, III, or IV content has the same current scope. The Secretary of State's retrieved compiled regulation volume is official but dated 2022, and its relevant section histories show their last amendment in 2001. [7] The dossier therefore does not use it to establish granular examination content; the current KDHE Class II document controls the limited future content boundary.

## Bank recommendation

**Evidence-supported recommendation:** If a future review-only candidate package is approved, use a single provisional, unique identity: **`ks-wastewater-class-ii`**.

The identity is supported because KDHE separates wastewater from drinking water, separately identifies Class II in its current application, and provides a current document explicitly labeled for the Class II wastewater examination. [2] [3] [8] Do not create a bank for the full Kansas wastewater-treatment stream and do not create Small System, Class I, Class III, or Class IV bank identities from this dossier.
