**Decision:** **Narrow**

## Credential and examination boundary

The supported credential boundary is the **Vermont Distribution Class D** operator certificate and its associated Vermont Class D examination. The controlling Vermont Water Supply Rule applies Class D to three defined public-water-system circumstances: a consecutive public system serving 500 or more people that has only a distribution system; a community system serving 500 or more people with multiple pressure zones or designated fire hydrants connected to transmission/distribution; and a non-transient non-community system serving 500 or more people with fire hydrants connected to the distribution system for firefighting. The rule requires affected systems to have a certified Class D operator or an eligible Legacy Distribution operator no later than July 1, 2029. [2]

For initial Class D certification, the rule requires a Secretary-approved certification-exam passing grade within the previous five years, applicable education and experience, an application, required fee, operator-in-training requirements, and other state licensing/certification requirements. The Class D experience requirement is 1.5 years. A candidate who does not qualify for the limited Legacy Distribution route must meet the Class D certification requirements, including the examination and applicable experience. [2]

Vermont DEC currently lists a distinct **Vermont Distribution Class D** computer-based test through its linked ABC/PSI testing route; DEC also lists Class D among the state-administered operator examinations. [4] [6] The 2025 official annual report states that Vermont uses customized WPI examinations for Classes 3, 4, and D because standardized WPI examinations did not align well with Vermont-specific requirements. [5]

## Readiness decision

**Narrow.** The current controlling rule, current DEC certification page, current exam page, and official program report establish a specific Vermont Class D credential and live examination boundary. They support a limited future, review-only candidate package confined to Vermont’s Class D classification, certification-pathway, and renewal-rule distinctions.

The public official record does **not** provide a current Class D examination blueprint, content outline, domain weights, need-to-know list, or state-approved technical study guide. The available certification and continuing-education topic categories are not an examination outline and must not be treated as one. Therefore, the evidence does not support a complete Vermont technical water-distribution exam bank or inferred WPI technical objectives. A broader package remains deferred unless DEC or the authorized testing program publishes a current Class D content outline or formally supplies a source-approved scope.

## Bank recommendation

**Do not propose a unique standalone bank at this stage.** If future work proceeds, it should be a tightly bounded, review-only **Vermont Class D regulatory addendum candidate package** attached only after overlap with any existing WPI-derived content has been checked read-only. It must not be represented as a full preparation bank for the Vermont Distribution Class D examination.

The candidate package boundary is state-specific certification classification, initial-certification pathways, the Legacy Distribution exception, and renewal requirements expressly stated in the current Vermont rule. It excludes broad technical distribution-operation content, technical WPI exam content, calculation coverage, exam-domain claims, and all material not independently supported by a current official Vermont source.

## High-level objectives for the narrow candidate package

1. Identify the public-water-system circumstances in which Vermont Class D distribution certification is required.
2. Distinguish the standard Class D certification path from the rule-limited Legacy Distribution path, including the July 1, 2029 deadline and its system-specific limitation.
3. Identify the state-stated Class D initial-certification and renewal boundaries, including examination, applicable experience, certificate duration, training-contact-hour requirement, and distribution renewal-category minimums.

## Learner-level scope and exclusions

**Intended future learner:** an experienced Vermont public-water-system operator who is pursuing, maintaining, or overseeing the Class D distribution credential. This is not introductory operator instruction and is not a substitute for supervised operational experience, an operator-in-training pathway, a treatment credential, or DEC-approved training.

**Included only:** explicit Vermont Class D legal classification triggers; stated certification and Legacy Distribution eligibility distinctions; the stated Class D examination requirement; the stated 1.5-year Class D experience requirement; the three-year renewal boundary; and the rule’s Class D renewal training-contact-hour categories.

**Excluded:** all Classes 1A, 1B, 2, 3, and 4 except where the rule expressly makes a treatment credential relevant to Class D; wastewater; collection systems; federal or other-state credential rules; treatment-process content; design engineering; hydraulic calculations; pressure-zone operation; hydrant, pumping, storage, or main-operation procedures; emergency response; monitoring and reporting procedures; and any claim about the number, weighting, topics, or difficulty of Class D exam questions. The rule’s continuing-education categories may define a narrow regulatory objective but do not authorize inferred technical exam coverage.

## Source freshness and conflicts

The legal source is current: DEC’s rules page designates the Water Supply Rule effective January 1, 2026 as current. DEC’s operator-exam page contains 2026 exam dates, and the PSI program page currently lists Vermont Distribution Class D. The annual capacity report is dated 2025 and is used only for its program-history statement that Vermont employs customized WPI examinations, not as the controlling legal source.

No material conflict affects this decision. The rule and current DEC certification page agree on the Class D credential, core eligibility structure, legacy pathway, and renewal framework. Exam fees and administrative delivery vary by state-administered versus computer-based route and are not within this package scope. Most importantly, none of the examined current official sources provides a public Class D technical content blueprint; that absence narrows the recommendation rather than authorizing inferred exam coverage.
