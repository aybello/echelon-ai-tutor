## Credential and examination boundary

Illinois does **not** operate a standalone “water distribution operator” credential. The Illinois EPA’s current program report states that Class D certification covers distribution systems and that higher-level certifications include distribution qualifications cumulatively. [1] The legally defined route that most closely and specifically corresponds to this matrix stream is the **Illinois water supply operator Class D examination classification** and the related **Class D Certificate of Competency** boundary: **pumpage, storage, and distribution**. [2] [3]

The Illinois rule requires separate Class A, B, C, and D examinations. [4] Accordingly, the narrowly usable examination target is the **Class D water supply operator examination**, not an invented generic Illinois “distribution operator” examination. The certification boundary must be described carefully: for issuance of a Class D certificate, the rule accepts a valid passing score on **any** water supply operator examination, plus the stated Class D education/experience conditions; it does not require passage of only the Class D examination. [5] A future candidate package must therefore be labeled as preparation for the **Class D examination scope**, not as a claim that the Class D examination is the exclusive route to Class D certification.

The official program remains active. Illinois EPA publishes 2026 and 2027 drinking-water examination schedules, and its most recent program report records 321 Class D examination attempts in calendar year 2025. [1] [8]

## Source freshness and conflicts

The strongest sources are the currently accessible official rule and statute pages, the Illinois EPA’s CY2025 program report, and the current 2026/2027 schedule. The operative rule pages show a 2017 last-amendment date, so they are not newly amended; however, they are the current official Administrative Code pages retrieved for this dossier. The CY2025 report is the most recent program-level report linked on the current Illinois EPA certification page and reports no program backsliding or policy change during that year. [1]

There is a material boundary clarification rather than an unresolved conflict. Illinois EPA’s FAQ uses simplified language that each level requires a passing score on the corresponding examination. [7] The controlling rule is more specific for **full Class D certificate issuance**: a valid passing score on any water supply operator examination is accepted. [5] The rule governs this dossier’s certification statement. At the same time, Section 681.210 establishes a distinct Class D examination. [4] This is why the supported target is a Class D examination-scope dossier, not a claim of an exclusive Class D certificate examination pathway.

No current Illinois EPA candidate handbook, Class D examination content outline, official job-analysis domain list, or Class D study guide was located among the reviewed current official certification pages and their linked programme materials. The general examination-purpose rule does not supply a defensible technical blueprint. [6] This source limitation prevents technical question-bank coverage from being inferred.

## Learner-level scope and exclusions

**Learner level:** prospective Illinois Class D water supply operator examinee, limited to the official Class D boundary of pumpage, storage, and distribution. This is an examination-preparation boundary, not site-specific operating authorization.

**Supported high-level objectives:**

- Identify that Illinois Class D competency is limited to pumpage, storage, and distribution. [2]
- Distinguish the separate Illinois Class D examination classification from a standalone distribution-only credential that Illinois does not offer. [1] [4]
- Recognize the state-defined difference between passing an operator examination and receiving a full Class D Certificate of Competency, including the additional Class D experience condition. [1] [5]

**Excluded pending stronger Illinois official evidence:** technical pump operation or maintenance; storage inspection or operational procedures; hydraulic calculations; pressure management; main installation or repair; disinfection; water-quality monitoring; sampling; cross-connection control; emergency response; recordkeeping; distribution-system regulatory duties; treatment processes; Class A, B, or C technical domains; and any site-specific procedure. These topics are not included merely because they can relate to distribution work; no current Illinois Class D technical blueprint or candidate handbook was found to support their examination allocation.

## Decision and bank recommendation

**Decision: Narrow.** Illinois has a current, specific and active Class D examination classification that maps to pumpage, storage, and distribution, and official sources support a tightly bounded candidate dossier. [2] [4] It is not **Suitable** for a technical Illinois distribution question bank because the reviewed official sources do not provide a Class D exam outline, candidate handbook, job-analysis domain list, or other current technical blueprint from which a question set could be traceably scoped.

**Bank recommendation:** **Do not propose or create a unique bank now.** Retain `il-water-distribution` as a state-specific research route with the usable label **Illinois Class D water supply operator examination — pumpage, storage, and distribution**. A uniquely named Illinois Class D candidate bank may be reconsidered only after Illinois EPA supplies or identifies a current official Class D content outline, candidate handbook, or job-analysis material that supports item-level technical objectives. Before any later bank decision, also perform the readiness-contract-required read-only recovery and overlap check against pre-existing U.S. Class I water-distribution packages; this dossier authorizes neither duplication nor replacement.
