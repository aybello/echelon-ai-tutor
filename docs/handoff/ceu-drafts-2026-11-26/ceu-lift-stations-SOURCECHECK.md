## Resolution of the 12 NOT COVERED lesson claims (2026-11-26, second-model review round 1)
Each claim was checked for accuracy, generality and whether it is stated as a numeric rule. All 12 are accurate, general and carry no numeric rule, so all 12 are kept. Wording changed where the review or the check showed an overstatement.
- M2 slowed only so far against high static head: kept (general pump-curve reasoning).
- M2 allowed starts per hour come from the motor maker: kept (points to the maker's data; no figure).
- M2 starts per hour peak when inflow is about half the pump rate: kept, reworded to state the simple-wet-well condition (steady inflow; fill and drain times trade off). The "try 200 gpm" test was removed because it did not match any stated pump rate. Derivation: cycle = V/q + V/(Q-q), minimised at q = Q/2.
- M3 set points adjustable from the panel: kept (rationale for continuous sensors).
- M3 high level alarm sits below the incoming sewer: kept, reworded to "normally set so that the warning comes before the sewer backs up, which in many stations is below the incoming sewer" (duplicate sentence in the figure caption removed).
- M3 PLC changes should be recorded and tested: kept (good practice, no figure).
- M3 typical alarm points include high, low, pump failure, power loss: kept (typical list).
- M3 typical signals sent from a station: kept.
- M3 daily volume = capacity x run time: kept (arithmetic); the limit now says the add-up holds only for time a pump ran alone.
