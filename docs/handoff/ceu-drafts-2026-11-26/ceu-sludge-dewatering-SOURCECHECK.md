# Source check: ceu-sludge-dewatering vs WEF MOP 11 (6th ed.) Chapter 33, the Wisconsin Advanced Wastewater Study Guide and Spellman Vol II

Checked 2026-11-26 while drafting, against the text extractions held locally: WEF Volume III Chapter 33 Dewatering (`ceusrc/chapters/ch33-dewatering-approx.txt`, read from the chapter table of contents through the Safety and Housekeeping section and stopped before the References), the Wisconsin DNR Advanced Wastewater Study Guide (February 2016; sections 21.1.1, 22.4.1, 24.3.6, 25.2.2, 26.2.1, 26.3.1) and, for belt tracking and plate-and-frame wording only, Spellman's Standard Handbook for Wastewater Operators, Volume II (CRC Press 2nd ed.), section 10.7.3. Verdicts: SUPPORTED, CONTRADICTED, NOT COVERED (the source is silent; the claim is general knowledge, arithmetic or a teaching inference and is flagged). Every quotation in the Source evidence column was matched against the extracted text by a script (case, hyphenation and spacing ignored) before this file was written; page markers are the printed page of the quote: `33-n` for WEF, `p. n` for the Wisconsin guide (its running footer) and Spellman's page (its running head). Table quotes from WEF come out of column-interleaved text, so a few table quotes read as fragments.

Page marker note: the WEF extraction places each page's running head before that page's text, so a quote is assigned to the last head that precedes it. Wisconsin guide pages are assigned to the next footer. These assignments were checked on known anchor sentences (for example WEF Introduction on 33-4, WI 22.4.1 on p. 64).
