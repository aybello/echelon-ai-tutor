# Ontario 309A — 500-Question Bank Blueprint

## Purpose and governing standard

This is the production allocation for an original Echelon Institute question bank for **Electrician — Construction & Maintenance (Ontario 309A)**. It deliberately follows the Red Seal **current-exam, previous-RSOS** task matrix. Red Seal currently identifies the newer Construction Electrician RSOS examinations as under development; do not silently switch the bank to that newer standard.[1]

The current interprovincial examination has 100 questions. The 500-question bank therefore provides five blueprint-weighted practice forms, rather than five unrelated topic collections.[2]

> The 500-question bank is an original study resource. It must never reproduce Red Seal sample items, claim to be an official exam, or imply a passing result.

## Authoring mix

The bank should contain **125 foundation**, **250 applied-scenario**, and **125 troubleshooting/calculation** items. Each Major Work Activity must preserve the same proportional mix where practical. A bank-level minimum of **100 calculation questions** is required; every calculation item must include explicit working in `steps` and a concise checking tip in `tip`.

Diagram-supported questions must represent at least **75 items**. A diagram can be reused only when the question learning objective changes materially; do not create superficial variants that differ only in a value or component label.

## Mandatory content rules

Every question must use four credible options, one correct answer, an original explanation, a task code, source metadata, and a precise blueprint objective. Distractors should correspond to realistic conceptual errors, unsafe sequencing, incorrect calculations, or plausible but inapplicable equipment functions. Do not use "all of the above," "none of the above," answer-length cues, copied sample-question wording, or wording that depends on a remembered Canadian Electrical Code rule/table number.

Question explanations should teach the decision, calculation, or troubleshooting logic. They must not provide unsafe step-by-step energized-work instructions. They should distinguish conceptual principles from site-specific design decisions and recommend following applicable safety procedures, licensed code resources, manufacturer instructions, and employer requirements when relevant.

## Source and review rules

The Red Seal task matrix is the governing blueprint source. Skilled Trades Ontario is the Ontario trade and curriculum-transition context. The Red Seal examination preparation guide governs exam-format claims, while the public sample-question page may be used only to understand item format—not to copy content.[1] [2] [3] [4]

Canadian Electrical Code rule-number, table-lookup, or verbatim-code questions are excluded until Echelon Institute has licensed access and an electrician SME has approved that content category. Manufacturer-specific setup procedures and proprietary software workflows are also excluded unless a rights-cleared source and reviewer are explicitly recorded.
