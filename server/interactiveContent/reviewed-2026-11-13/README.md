# AI-reviewed OIT game expansion, 2026-11-13

Father explicitly authorized releasing the current OIT water and wastewater exercises with Carbon or GPT 6.1 Sol content review rather than a human technical review. This release uses actual `gpt-6.1-sol` item reviews of independently generated `gemini-4-argon` content and a separate Sol full-corpus release review. It does not claim human review, calibrated difficulty, official Ontario exam blueprint alignment, expert approval, or exam-pass certainty.

The intended approved corpus contains **671 new exercises**, 374 for `oit` and 297 for `oit-ww`. The immutable 103 water and 107 wastewater legacy exercises remain unchanged. Other courses receive no new items in this release. `electrician-309a` remains excluded. These totals do not mean every game reached 100 or that the 228,000 target is complete. Exercise counts are not unique scientific-concept counts.

`release.json` contains only learner payloads and explicitly estimated difficulty classifications. `approval.json` binds the complete private authoring corpus, exact selected IDs, exact checked versions, an independent UUID-based release token and the literal bank bytes. `active-pins.json` contains the exact two manifests approved by Sol before real compilation. `content-review-approval.json` records the actual independent verdict, declared limitations and provider-response checksum. Normal builds and the runtime retain all bank, manifest, shard and immutable legacy checks. There is no skip-trust option or automatic approval from a compiler input.

Raw source snapshots, verification excerpts, generation/review requests, candidate ledgers and rejected exercises stay outside the repository, client assets and runtime bank. Private evidence was matched locally to actual saved primary text. Sol reviewed independently worded factual seeds; it did not independently retrieve the primary publications. Older source rights notes describe unknown original remote retrieval timestamps. Current private source records explicitly identify actual local snapshot retrieval and preserve that original remote dates are unknown. No dates or blanket source reproduction licences were invented.

One formerly passed pump-cavitation guarantee with a later unresolved concern was excluded and replaced with an eligible spare. A further 54 items that failed operating, safety or legal-language guards remain private. Other rejected, duplicate or unsupported drafts were not selected. No pricing, payment, team entitlement, regular quiz bank, learner history or production database changes are part of this release.

The opt-in `owner-authorized-ai-oit-v1` route applies only to original supplementary routine conceptual material in these two OIT courses. Default per-item human review and the existing sampled-human risk route remain unchanged. All source, metadata, calculation, hash, duplicate/conflict, legal and software checks remain active. AI policy acceptance is counted separately from human review.
