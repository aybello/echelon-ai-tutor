# Echelon study fonts

These Latin variable WOFF2 subsets are the same Inter and Fraunces fonts used in the approved design preview. The app serves them locally rather than depending on Google Fonts at runtime.

- Inter: https://github.com/google/fonts/tree/main/ofl/inter
- Fraunces: https://github.com/google/fonts/tree/main/ofl/fraunces

Both are licensed under the SIL Open Font License 1.1. The corresponding original license texts are included in this directory.
